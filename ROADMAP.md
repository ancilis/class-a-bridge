# Roadmap

This roadmap describes possible directions, not promises, dates, eligibility interpretations, or commitments to support a future official process. Security, privacy, accessibility, current official requirements, and the usefulness of the ungated local product remain release gates.

## Maintain 1.x

- Track official Class A rule and schema changes through human-reviewed, source-pinned releases.
- Expand deterministic PDF fixture coverage and explain extraction confidence more clearly.
- Improve browser-storage recovery diagnostics and archive compatibility testing.
- Add more editable document formats where local generation remains safe and maintainable.
- Broaden keyboard, screen-reader, print, mobile, and cross-browser regression coverage.
- Publish reproducible build provenance and signed release artifacts when repository hosting supports it.

## Candidate future work

- Optional, local optical character recognition that downloads no document content and has an explicit resource/supply-chain review.
- Additional fictional industry samples and reusable public-site vertical content.
- Provider-controlled collaboration designs that preserve encryption, consent, auditability, and a usable fully local mode.
- Planning guidance for Class B, only after official sources and the product boundary are reviewed. A planning module would not turn the 1.x Class A workspace into a complete Class B platform.

## Explicitly outside the current roadmap

- Automated FedRAMP submission or government impersonation.
- Claims of certification, approval, guaranteed eligibility, or guaranteed acceptance.
- Automatic control completion from extracted text or a generic Trust Services Criteria crosswalk.
- Remote artificial-intelligence interpretation of confidential documents by default.
- Mandatory accounts, cloud connections, assessment telemetry, or paid gates on core preparation/export features.

Open a public proposal for roadmap changes that do not disclose customer or assessment data. Regulatory and trust-boundary proposals require the reviews described in [GOVERNANCE.md](GOVERNANCE.md).
