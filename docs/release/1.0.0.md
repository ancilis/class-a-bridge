# Class A Bridge 1.0.0 release notes

Class A Bridge 1.0.0 is the first open-source release of Ancilis's local-first FedRAMP 20x Class A preparation workspace. A compliance team can start in a browser without an account, answer eight high-value questions for an explainable preliminary result, and continue through scope, SOC 2 materials, Class A requirements, evidence, actions, reports, and package scaffolding.

## Highlights

- Three first-run paths: local SOC 2 PDF, manual entry, and the complete fictional Acme Metrics workspace.
- Deterministic local text extraction with page/snippet/confidence and confirm/edit/ignore; no remote model or document upload.
- Complete versioned Class A preparation registry with all 23 mandatory records and seven dedicated Key Security Indicator flows.
- Many-to-many SOC 2 mappings, evidence candidates, freshness, owners, actions, and clear uncertainty.
- Human-readable artifacts, official-schema JSON validation, friendly editable errors, numbered package ZIP, and immutable final-review snapshot.
- IndexedDB/local fallback, standard backup, browser-native password protection, strict restore, deletion, and redacted advisor handoff.
- Static public website, guidance/legal pages, open-source community/security documentation, and an optional contact-only endpoint.
- Installable offline PWA, accessible component/flow coverage, security headers, threat model, and no-project-data network gate.

## Official baseline

This release uses FedRAMP Consolidated Rules for 2026 catalog `2026.07.14.01` at commit `12fe1b60f578ab448c26d143baac99d16d8bfe14`, verified 2026-07-17. It vendors eleven official JSON Schema files whose filenames are dated 2026-06-24, each with recorded source, schema version, retrieval date, byte size, and SHA-256 checksum and no local changes.

The official `FRC-CLA-RFR` reference to `CPO-CSF-CPM`, despite the latter's July 14 removal of Class A applicability, is preserved and flagged “Needs FedRAMP confirmation.” The software does not silently resolve the inconsistency.

## Privacy and security

The bridge application has no account, assessment analytics, remote artificial-intelligence service, remote document parser, remote error reporting, or third-party runtime script. Project data is local to the browser unless a user explicitly downloads and later shares an export. The optional website contact service is separate and accepts contact fields only.

## Boundaries

Class A Bridge helps prepare and organize records. It does not certify, authorize, approve, audit, independently assess, provide legal advice, submit an application, or guarantee eligibility or acceptance. Providers review and approve all representations and submit their own materials.

Version 1.0 does not include optical character recognition, cloud integrations, server collaboration, Class B/Class C workspaces, or automated submission. See [CHANGELOG.md](../../CHANGELOG.md) for the detailed release record and [ROADMAP.md](../../ROADMAP.md) for non-committed future directions.

## Build outputs

- Canonical static release: `dist/class-a-bridge`
- Website: `apps/website/out`
- Browser application: `apps/bridge/dist`
- Optional contact handler: `apps/contact-api/dist`

The canonical release serves the website at `/`, the workspace at `/app/`, and contains `release-manifest.json` plus `/downloads/class-a-bridge-1.0.0-source.tar.gz` generated from Git `HEAD`. Build from the tagged clean checkout with Node.js 24, pnpm 10.33.0, `pnpm install --frozen-lockfile`, and `pnpm verify`.
