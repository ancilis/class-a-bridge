# Class A Bridge 1.0.0 release gate

Version 1.0.0 is **not released**. This file records the promotion gate from the
0.9.0 Public Beta; it is not a release announcement.

Promotion requires all critical automated gates plus evidence of:

- qualified human technical, compliance, and claims review for every mandatory
  SOC 2 mapping playbook;
- substantive human review of representative generated package outputs;
- completed Chromium, Firefox, and Safari/WebKit real-hardware verification,
  including PWA installation, offline restart, persistence, export/restore, and
  network observation;
- completed primary-workflow WCAG 2.2 AA manual review;
- completed moderated usability sessions with the three representative roles;
- an evidence-based release checklist with no critical failed or blocked item.

Until those records exist, all builds and public copy must use the 0.9.0 Public
Beta designation. See [0.9.0.md](0.9.0.md) and
[RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md).
