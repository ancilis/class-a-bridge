# Class A Bridge 0.9.0 Public Beta release notes

Class A Bridge 0.9.0 Public Beta is Ancilis's local-first FedRAMP 20x Class A
preparation workspace for compliance teams with a SOC 2 Type II report. It is a
publicly distributable beta, not a certification product or a government
determination.

## What changed

- Corrected effective Class A normalization for every selected rule with a
  `varies_by_class.a` branch, including `IEC-CSO-FIR` and `IVV-CSX-AIA`.
- Separated individual official force, official Class A aggregate obligation,
  product inclusion, and Ancilis workflow priority.
- Added field-level regulatory provenance, machine-readable integrity and
  rule-selection audits, and a checksum-verified report generator.
- Added a structured SOC 2 control inventory, CSV template/import/export, and a
  deterministic reuse-suggestion engine built from versioned Ancilis playbooks.
- Added an explainable SOC 2 reuse workspace and SOC 2 Reuse and Gap Report.
- Stabilized the formerly flaky jsdom workflows with feature-level evidence
  coverage, focused package-finalization assertions, and a deterministic
  one-worker bridge test configuration; no timeout was increased.
- Made source-archive release assembly independent of `.git` metadata and added
  truthful source provenance, including protection against accidentally using a
  parent repository's commit for a nested Git-less archive.
- Hardened attachment ownership, shared-attachment deletion, legacy IndexedDB
  cleanup, metadata-only restore collisions, and same-project restore warnings.
- Updated the website to state that mapping suggestions are deterministic,
  local, explainable, and require human confirmation.

## Why this is a public beta

The software and automated regulatory integrity gates can be tested by this
release process. The repository does not contain evidence that qualified human
reviewers approved every mandatory mapping playbook, that a representative
generated package received substantive final review, or that the full manual
real-hardware matrix was completed. Those remain gates for 1.0.0 and are not
fabricated here.

- Official JSON Schema files: eleven pinned files dated 2026-06-24, with
  checksums in the schema manifest and no local changes

The upstream `FRC-CLA-RFR` reference to `CPO-CSF-CPM` is preserved and disclosed
as an upstream inconsistency. Class A Bridge does not silently rewrite it.

## Product boundary

Class A Bridge assists with application preparation. It does not certify,
authorize, approve, audit, independently assess, provide legal advice, submit
an application, or guarantee eligibility or acceptance. Providers review and
approve their own representations.

## Canonical build outputs

- Combined static release: `dist/class-a-bridge`
- Marketing website: `apps/website/out`
- Local-first application: `apps/bridge/dist`
- Optional contact handler: `apps/contact-api/dist`

The combined release includes the source archive, source provenance,
checksums, and release manifest. The source archive must build without a `.git`
directory by running the documented pinned-toolchain workflow.
